# 강사 아카이브

기업 교육 담당자가 강사를 검색하고 프로필, 강의 이력과 평가를 관리하는 웹사이트입니다.

## 열기

압축을 풀고 `index.html`을 브라우저로 엽니다. 또는 이 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`에 접속합니다. 프로필 사진은 공개 원본에 연결되어 인터넷이 필요합니다.

## GitHub Pages

저장소의 기본 브랜치 루트에 이 폴더 안의 파일을 올립니다. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 고르고 기본 브랜치와 **/(root)**를 선택합니다. Pages가 표시한 주소에서 검색과 프로필을 확인할 수 있습니다.

## 데이터와 저장

- 초기 데이터는 `data.js`에 포함되어 있습니다. 각 강사 프로필에 원문과 사진 출처를 연결했습니다.
- 강사는 출처의 프로필 ID와 이름·직함으로 구분합니다. 출생연도에 출처가 있으면 링크를 표시합니다.
- 행사 공지, 개최 확인, 공개 후기를 구분합니다. 행사의 실제 개최일 대신 후기 게시일만 확인한 경우 둘을 별도로 표시합니다. 장소가 공개되지 않은 건에는 주최 기관을 행사장으로 기입하지 않았습니다.
- 기본 목록의 출처는 [채널PNF 공개 프로필](https://www.pnf.ac/speakers)입니다. 강의 이력은 채널PNF 후기, 주최 기관 공지, 한국강사신문 재게시 기사, 뉴스1 보도 등에서 보완했습니다.
- 새 강사, 프로필 수정, 강의 이력과 평가는 현재 브라우저에 저장됩니다. 팀 계정, 공유 데이터베이스 및 자동 동기화는 구현 범위에 포함되어 있지 않습니다. 백업으로 변경 기록을 내보내고 불러올 수 있습니다.


## 강사 추가 검색과 이미지 입력

- 이름으로 기존 강사 목록과 한국어 위키백과·위키데이터의 공개 인물을 조회합니다. 추가 키워드는 후보의 소개와 직함을 대조하는 데 사용합니다. 검색 결과의 출처와 사진을 검토한 뒤 등록합니다.
- 언론 기사와 강의 주제는 후보 검색 화면의 뉴스·웹 검색 링크에서 추가 확인할 수 있습니다. 공개 인물 자료에 강연 이력이 없으면 직접 입력합니다.
- 강사 사진과 이력이 있는 이미지를 함께 첨부할 수 있습니다. 이미지 속 한글·영어는 브라우저에서 인식합니다. 문자 인식 코드와 언어 데이터의 첫 로드에는 인터넷이 필요합니다. 인식 결과는 저장 전에 수정할 수 있습니다.

## CSV와 강의 평가

- 상단의 **CSV 내보내기**로 전체 강사 목록을 내려받아 Excel에서 열 수 있습니다. **CSV 가져오기**는 쉼표로 구분된 CSV(UTF-8 또는 CP949)를 받습니다. 새 강사는 강사 ID를 비우고, 이름과 소속·직함을 입력합니다. 기존 강사를 수정할 때는 내보낸 ID를 유지합니다.
- CSV는 프로필 교환용입니다. 강의 이력과 평가, 첨부한 로컬 사진을 함께 보관할 때는 JSON 백업을 사용합니다. CSV로 프로필을 수정해도 기존 강의 이력과 평가는 유지됩니다.
- 평가는 강의 주제와 실제 강의 날짜로 묶으며, 같은 회차의 등급별 건수를 표시합니다. 프로필 오른쪽에는 최근 평가 강의의 등급과 최근 강의 날짜 및 프로그램을 표시합니다.
- 기존 점수는 5→S, 4→A, 3→B, 1~2→C로 표시합니다. 이전 평가에 강의 날짜가 없으면 '강의 날짜 미확인'으로 표시합니다.


## 공개 강사 DB 갱신

프로필에는 쉼표로 구분한 여러 분야를 지정할 수 있습니다. 강의 주제는 한 줄에 한 건씩 관리합니다. 분야가 같아도 강사별로 검색됩니다.

검토한 공개 자료를 JSON 배열로 정리한 다음 `python scripts/update_speakers.py 검토한자료.json`을 실행합니다. 각 항목에 `name`, `role`, `source`를 넣고 필요에 따라 `category`, `topics`, `career`, `photo`, `sources`, `events`를 넣습니다. 동명이인은 이름과 소속·직함을 대조합니다. 기존 인물임이 확인되면 `matchId`에 기존 ID를, 다른 사람으로 확인되면 `confirmedDistinct`에 true를 지정합니다. 출처가 확인된 정보만 넣고 자료에 없는 날짜·장소·사진은 비워 둡니다.

스크립트는 공개 목록을 갱신하고 `db-history`에 한국시간이 들어간 사본을 남깁니다. 사이트 하단 링크에서 이전 버전을 내려받을 수 있습니다. 사용자가 브라우저에서 등록한 내부 평가와 프로필 변경 내역은 날짜가 붙은 JSON 백업으로 내려받습니다.
